# Техническая документация

[Обзор проекта](../README.md) содержит назначение, основные возможности,
архитектурную схему и быстрый старт. Здесь собраны подробные инструкции
и сведения о текущем состоянии реализации.

| Документ | Назначение |
| --- | --- |
| [Установка и настройка](SETUP.md) | mise и uv, изолированный локальный запуск, тестовый чат, подключение Instagram, материалы бизнеса и команды проверок |
| [Архитектура и API](ARCHITECTURE.md) | Компоненты backend, очередь SQLite, контекст консультации, отправка и административные маршруты |
| [Панель администратора](ADMIN_PANEL.md) | Настройка и диагностика агента, тестовый чат, подсказки и ручное вмешательство |
| [Размещение и эксплуатация на VPS](DEPLOYMENT.md) | Подтверждённое серверное состояние, разделение окружений, systemd, Nginx, прокси, резервные копии и откат |
| [Миграция существующей SQLite](MIGRATION_SUGGESTIONS.md) | Явное обновление прежней схемы SQLite, резервная копия и откат |
| [Интеграция Umnico](UMNICO_API.md) | Используемые методы, авторизация и ограничения контракта |
| [Проверка готовности](IMPLEMENTATION_PROGRESS.md) | Результаты автономных и интеграционных проверок, подтверждения и границы приёмки |
| [Проверки консультаций](CONSULTATION_CHECKS.md) | Сценарии оценки ответов модели и извлечения заявки; сценарии не являются результатами реальных запросов |
| [Состояние и дальнейшие действия](ROADMAP.md) | Текущие ограничения, риски и приоритеты развития |
| [Границы первой версии](IMPLEMENTATION_PLAN.md) | Согласованный объём первой версии и критерии реализации |

Для первого знакомства используйте изолированный тестовый чат из
[локальной настройки](SETUP.md#локальная-разработка-параллельно-с-production).
Он может выполнять платные запросы OpenRouter. Автономные тесты с подменённой
сетью описаны отдельно в [разделе проверок](SETUP.md#проверки).
